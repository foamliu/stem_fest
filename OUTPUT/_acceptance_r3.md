### 1.2 确认的两个「烧进画面」文字事故（本轮新发现）

#### ★ 镜 18 — 「豆包AI生成」模型水印（A 级）
- **现象**：投影仪机身侧面印着清晰的 `豆包AI生成` 六个字（8 帧全中）。
- **性质**：H3 把训练语料里的**生成式 AI 水印**当场景元素画进了道具表面。
- **为什么此前漏检**：位置在 **0.72H**，落在字幕带（0.76–0.96H）**之外**；
  且是「小字块」，nseg 只有 12，被 v3 检测器的连通块阈值滤掉。
- **根因**：镜 18 旧 prompt 是**全片唯一没有文字禁令的镜**（姊妹镜 15/16 都有），
  而它偏偏是「特写一台机器」—— 特写道具 + 无禁令 = 模型自由发挥表面纹理。
- **修复**：新增 `NO_TEXT_SCENE`（穷举文字载体 + 点名"AI 生成角标"）；
  明写设备为"磨砂金属、无任何印刷/丝印/贴标"；seed 9631 → 9633。
- **产物**：`18_sicheng_presses_start_button_00005_.mp4`

#### ★ 镜 104 — 车厢 LED 信息屏伪汉字（A 级）
- **现象**：车厢顶部 LED 屏有清晰伪汉字（红「驩 忻苜鑧」+ 绿「用」+ 彩色图标），
  端墙上另有一块**带字的金属告示牌**。
- **根因**：镜 104 是「全景车厢 + 无文字禁令」，H3 把"高铁车厢"这个概念里
  记忆的**公告信息**全补上了（它不知道要留白）。
- **为什么此前漏检**：位置在 **0.04–0.14H**，比字幕带**更靠上**。
- **修复**：同 `NO_TEXT_SCENE`，并**点名**"车厢顶部/车门上方没有发光 LED 屏、
  没有报站屏、没有车厢号牌、没有告示牌/广告/时刻表"；seed 9730 → 9736。
- **产物**：`104_zhong_walks_away_into_night_00004_.mp4`
- **验证（像素级 A/B，决定性）**：

  | 版本 | 端墙上方(0–0.22H, 0.45–0.98W) 发光像素 · 6 帧 |
  |---|---|
  | `_00003_`（旧） | 18775 / 15682 / 16810 / 20062 / 21267 / 23567 |
  | `_00004_`（新） | **0 / 0 / 0 / 0 / 0 / 0** |

  ⇒ LED 屏**彻底消失**，禁令精准生效。

### ★ 本轮证伪的检测器（重要，避免后人重走）
1. **`_scan_skytext.py`**（天区高饱和发光块）：349 条候选，绝大多数是**行李架金属格栅**
   （规则网格 = 大量连通块）—— 不可用。
2. **`_led_probe.py` 红通道**：被**红领巾**淹没（每镜 red=100%）——必须改用
   "**深色底 + 局部高饱和**"才能定位 LED 屏。
3. **SAM3 text 提示词**：对同样的镜，**旧版（有水印）coverage=0.0056，
   新版（疑干净）coverage=0.0278** —— **方向反了**，证明 SAM3 的 open-vocab
   "text" 不能用于水印验收。
4. **`_textface_probe.py`**（笔画 top-hat + 碎块计数）：分数在稻叶/战壕段普遍偏高，
   **只能排序、不能判定**（与 README §6.10.10 结论一致）。
5. **`_wm_ab.py`**（A/B 行段带宽）：梯度噪声大，新旧不可比（seed 不同⇒画面不同）。

⇒ **再次确证铁律：扫描器只能压缩候选空间，"有没有字"必须读图。**
