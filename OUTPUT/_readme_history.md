**⑥ 五路接法全量对照**（`_diag_concat_ab.py` / `_diag_demuxer_join.py` / `_diag_prepass_shortest.py`，7 镜）：

**⑦ 中途出现的疑点（必须记下来，避免下次重复踩）**：收尾时探到**旧母版**（9/20 的 `full_cut.mp4`）
音轨 525.626 s ≈ 画面 525.625 s，"看起来是齐的"，一度与结论冲突。查到最后发现这是一条**判据本身的陷阱**：

1. 同一批片段（9/14–9/20）逐段余量实测全部 > 0 ⇒ 若按"两条轨各自接力"的旧路径拼接，音频内容必然多出 ~2.5 s；
2. 但「音频**被钉到**画面长度」（正确修法）与「音频**被截断到**画面长度」（`-shortest` 之类，内容仍在漂）
   会给出**同一个长度读数**：本次修好的新母版音轨**同样是 525.626 s**（钉长后 Σ段长 = Σ画面 = 525.625 s，再经 AAC 编码 +1 ms）。
   ⇒ 旧母版（音轨 48 kHz，说明当年 ffmpeg 命令与 9/21 版不同）**到底属于哪一种，无法由长度判定**；
   该文件已在收尾中被新母版覆盖，**无法再实测内容偏移**。
3. **结论（判据修正）**：`|音轨−画面| ≈ 0` 只是**必要条件，不是充分条件**。
   唯一可靠判据是**逐镜测内容偏移**（`_diag_av_match.py`：源片段音频 vs 成片窗口的包络互相关）。

**⑧ 教训**：整套验收流程（`_verify_fullcut.py` 抽帧、`_audit_asr.py` 台词、人脸一致性、
水印探针）**全都是"看画面/听词"**，唯独没有"看口型对不对"的检查 —— 所以它能一路潜伏到交付。

#### 6.10.6 ★★★ 事故复盘 ×4：镜 97/99/104/105（2026-09-17）

> 这一轮的 4 个问题**根因各不相同**，但都属于同一类元问题：
> **我们对 H3 的「默认行为」估计不足**。逐条记录，避免重犯。

**① 镜 97 —— 阿拉伯数字被念错（`400 米栏` → 「四十米栏」）**

| 项 | 内容 |
|---|---|
| 现象 | 台词 `1959 年…我打破过全国 400 米栏纪录` 被念成「**四十米栏**」（丢了百位） |
| 根因 | 台词里写**阿拉伯数字**，且**数字与量词间带空格**（`400 米栏`）→ H3 断词出错 |
| 修法 | 台词一律写**中文数字且不带空格**：`一九五九年…四百米栏` |
| 验证 | ASR 回读 = 「一九五九年，我打破过全国**四百米栏**记录。」✅ |
| ★ 泛化 | 闸门 `_verify_prompt_clean.py` 新增规则：`(?<=说：)[^\n]*\d{3,}` 等 → 一上线就**顺带抓出 4 处同类隐患**（镜 28/48/76/90 的阿拉伯年份），已一并修掉 |

**② 镜 99 —— 说话人身份错误（张书扬抢了钟南山的台词）**

| 项 | 内容 |
|---|---|
| 现象 | 该镜是钟南山讲「我父亲说…」的名场面，但**开口的是张书扬** |
| 根因 | `ref1 = G_ZHANG_ZN`（**张书扬+钟南山合影**）→ **画面里有谁，H3 就可能让谁说话** |
| 修法 | ① 换成单人照 `G_ZN_SOLO`；② prompt 明写「画面里**只有**那位老年男性一个人」「只有他一个人入镜、只有他一个人说话，画面里不要出现任何学生或其他人」 |
| 验证 | 读图 = 画面仅钟南山一人 ✅；SAM3 覆盖率 0.395 → **0.242** 客观证实少了一人 ✅ |
| ★ 教训 | **R2V 的参考图是「说话人候选池」** —— 单人台词镜**绝不能**接多人合影作 ref1 |

**③ 镜 99 追加 —— 画面描述被当台词念了出来（新污染类型）**

| 项 | 内容 |
|---|---|
| 现象 | 第一版修完后 ASR 得到「体育竞技不能**成就一走过来的笃定**，这竞技不能成为…」—— **多念了半句** |
| 根因 | prompt **画面描述**里写了「语气里没有炫耀、只有一种**走过来的笃定**」。这个抽象 `…的X` 短语**紧邻 Audio 台词区、且以"的"结尾像话术** → 被 H3 归入语音流 |
| 修法 | 改成**具体可拍的行为**：`他开口讲述一段改变了他一生的话，说的时候目光平稳、神情克制、没有炫耀的意思；` |
| 验证 | ASR 回读核心台词正确，杂音消失 ✅ |
| ★ 新闸门 | `_verify_prompt_clean.py` 新增「抽象情绪名词化」规则（`一种…的X`/`带着…的X`/`有一种…的X`），旧写法命中、新写法通过 |

**④ 镜 104 —— 列车行进逻辑矛盾（车没停，人已出门）**

| 项 | 内容 |
|---|---|
| 现象 | 剧情是「老人下车」，但画面里**车还在行进**，末帧门外是**一片纯黑虚空**（不是站台） |
| 根因 | **H3 对"列车场景"的默认态就是「行进中」** —— 只要 prompt 提到车厢/窗外，它就自动加运动。即使写了"下车"也压不住 |

| 验证 | 读图 = 门外是**灯火通明的静止站台**，无运动模糊 ✅ |
| ★ 教训 | 与 §6.10.3 镜 31 同源 —— **环境/状态锚点必须写在 prompt 开头**，写在中段会被稀释 |

**⑤ 镜 105 —— 纯 T2V 导致人物漂移（服装/人数全错）**

|---|---|

| 根因 | 旧版是**纯 T2V**（`ref1=None, ref2=None`）—— **没有任何参考图**，人物全靠模型自由发挥 |
| 修法 | 改 **R2V**：`ref1=G_FOUR`（四小强合影）+ `ref2=SCENE`；prompt 写明「四位穿校服的初中生（两男两女）」「严格照 `<Picture 1>`（两男两女共**四个人，一个都不能少**、脸不能变）」 |

**⑥ ★★ 本轮第 5 个隐性坑：长镜 + 20 步 = 必 OOM（镜 99 实测）**

| 项 | 内容 |
|---|---|
| 现象 | 镜 99 用 `0.6 MP + 20 步` 直接 `torch.OutOfMemoryError`（节点 `SamplerCustomAdvanced`） |
| 根因 | 16GB VRAM 的**帧数临界点**：`9s → 226 帧`能过（镜 97 ✅），`10s → 243 帧`就爆 |
| 修法 | 单镜降到 `--mp=0.4` 跑通（显存余量 13 GB），再**事后恢复到 1056×608** |
| ★ 关键 | 降 mp 会改分辨率（864×480），若不恢复，`_concat_video.py` 会检测到**规格不一致**，回退成「**全片 126 镜重转码**」—— 为一镜损失整片画质 |
| 工具 | 新增 `_upscale_shot.py`：**只**把这一镜用 lanczos 升到 1056×608 |
| ⚠️ 注意 | 它是**恢复规格**不是"真超分"（864→1056 只有 1.22x，细节不会凭空长出来）。要真超分需另配 ESRGAN 类模型 |
| 帧数守恒 | 升分后**帧数必须不变**（243 → 243），否则拼接会错位。`_upscale_shot.py` 内置该检查 |

> **帧数量化公式**（供核对，别再算错）：
> `H3 内帧 = ceil(秒 × 24)` → `k = ceil((内帧 − 5) / 17)` → **`实际帧 = 17k + 5`**
> 例：9s→216→k=13→**226 帧**；10s→240→k=14→**243 帧**；5s→120→k=7→**124 帧**。

|:-:|---|---|---|
| **①** | **`NO_SPEECH` 里的\"听不清任何词句\"会诱发 H3 编造语音** | 白屏日记卡镜 46/74/105 **本应零台词**，却分别念出「大妹子。」「谁了？」「嗯。」<br>它们的 Audio 都写着：`远处零星的人声杂音，听不清任何词句。` | **"听不清 X" ≠ "没有 X"**。把整个人声描述换成**物理声源**：<br>`远处有节奏的机械轰鸣与低频震动，持续而平稳。` |
| **②** | **`Audio:` 段里的舞台指示会被念出来** | 镜 97 的 Audio = `他平静地说：一九五九年，…`<br>ASR = 「**他平静地说：**一九五九年，…」 | 把**表演提示移到画面描述**（H3 用画面演语气），Audio 段只留 `他说：<台词>`。<br>全片 **39 处** `X地<动词>：` 已统一降级（`_fix_stage_direction.py`，可重复执行） |
| **③** | **同音字是系统性风险**（H3 按发音重建台词） | 稻子→豆子/哨子/瘦子（4 处）、继光→季光/激光（2 处）、袁爷爷→原夜、物资→日再、戴好→带好 | ⛔ **加拼音锚点是错的**（`稻子（dào zi）` 实测变成「对子导爱」，**更糟**）<br>✅ **正解：改句子** —— 换同义词 / 加字 / 改语序：<br>`这是普通稻子`→`这是田里最普通的稻子`；`就为了一株稻子？`→`就为了田里的一株禾苗？`；`想让稻子多结一点`→`想让稻穗多结一点谷粒`；`袁爷爷`→`袁隆平爷爷`；`战前物资紧张`→`战前补给紧张`；`戴好`→`记得戴上`<br>✅ 必须原样保留的词（史实人名）⇒ **换 seed 重跑**（同音错是概率问题） |
| **④** | **Audio 段里的\"行为约束\"也会被念**（**同类错误第 4 次**） | 为修镜 18「那就进模型」被念 3 遍，加了 `一句话说完就停，不重复：`<br>ASR = 「**一话说完就停，不曾晚。绝缝事，**那就进模型。」 | **Audio 段里不许有任何"对模型说的话"**，包括最无害的"只说一遍"。<br>重复问题靠 **换 seed 重跑** + **后期裁剪**解决 |

**闸门升级（本轮新增 6 条）**

| 新增规则 | 拦截对象 |
|---|---|
| `听不清任何词句` / `人声杂音` / `模糊的人声` | 音景免责声明（会诱发编造语音） |
| `没有说出台词` | 语音元词汇 |
| `[^。；\n]{0,8}地(说\|问\|喊\|答)[：:]` / `地(说\|问\|喊\|答)道[：:]` | **Audio 里的舞台指示**（会被念出来） |

> ★ 新规则上线后**立刻抓出 38 镜**含 `X地<动词>：`（其中只有镜 97 被实际念出来 —— 短副词侥幸逃过）。

#### 6.10.10 ★★★ 事故复盘：**字幕泄漏检测器失效 + H3 把"喊出的专有名词"烧成字幕**（2026-09-17）

> 本轮**最严重的一次"验证工具本身失效"**：全片扫描报 `0/126 干净`，
> 但**抽帧读图后发现镜 36 画面里赫然烧着「继光哥」「你听见没」**。
> 这是 §6.6/§6.7 的**再犯**，且暴露了**闸门本身的三代缺陷**。

**第一部分：检测器为什么失效（三轮演进，每轮都被实测打脸）**

| 版本 | 判据 | 结局 |
|---|---|---|
| **v1** | 「亮像素中"紧贴暗像素"的比例 ≥ 0.55」 | ⛔ **漏检镜 36**。那是**夜间暗场**：`dark` 掩膜近全屏 ⇒ dilation 后 halo 也近全屏 ⇒ 比例被稀释到 0.30。**该判据在暗场必然失效** |
| **v2** | 「滑动窗 + 列投影离散段数 ≥4 + 平均字宽 ≤6%」 | ⛔ **误报 96/126**（几乎全片）。把**人脸高光、牙齿、白领口、桌面反光**全算了进去 —— 这些同样是"多个窄亮块横向排列" |
| **v3** | v2 + ①近中性白（`min(R,G,B)≥205 且 |R−B|≤14`）②仅在 **0.76–0.96H** 带内 ③**连通块拓扑**（`_blobs`：块数 ≥8 且最大块 <40% 总面积） | ✅ 7/126 候选 ⇒ **读图复核后真泄漏 2 镜** |

> ★★ **v3 的关键是"连通块拓扑"**：列投影（横向有没有亮像素）对**大色块**与**字形**是一样的；
> 但连通块完全不同 —— **字形是"很多小岛"，脸颊/额头是"一片大陆"**。
> 这条判据把镜 02（妈妈明亮的脸）与镜 60（暖色高光）从命中里剔除了。

> ★★★ **方法论铁律（比判据更重要）**：
> **扫描器只能把候选缩到个位数，"到底有没有字"必须读图确认。**
> `_scan_text_rows.py` 的注释里写着"这是筛查器不是判官"，但**本轮我一度把它当判官用了**
> （看到 `0/126` 就以为干净）⇒ 差点放过真泄漏。
> ⇒ 固化为 `OUTPUT/_textrows_verdict.py`（**人工复核裁定表**）+ `_selftest_textrows.py`（**正负例自测**）：
> · 正例（应命中）：镜 36 四帧 · 负例（不该命中）：镜 02 脸 / 镜 60 高光 / 白条带
> · **检测器任何改动都必须先过自测（4 通过 / 0 不通过）**，否则不许用来下结论。

**第二部分：真泄漏只有 2 镜，根因是"喊出的专有名词"**

| 镜 | 烧进画面的字 | 原因 |
|:--:|---|---|
| **36** | 「**继光哥**」「你听见没」 | 台词 `小战士喊：黄继光哥！你听见没！打赢了！` |
| **61** | 「**袁隆平爷爷**」 | 台词 `男生脱口而出：袁隆平爷爷，您……` |

> ★★ **共同点：泄漏的都是台词里"被喊出来的专有名词"** —— 而且**只有名字那几个字**，
> 后面的正文（「你听见没」是唯一例外）没被烧。
> ⇒ 定性：**H3 把"喊出一个名字"理解成了"给这个人打字幕名牌"**。
>
> ★ 关键反证：**镜 36 的 prompt 里本来就有很强的守护句**
> （`★ 全画面不得出现任何可读的文字、字幕或符号。画面上没有任何文字、字幕或标识`），
> **照样泄漏** ⇒ 再次确认 §6.7 的结论：**"禁止写文字"的守护句挡不住**，
> 因为触发源是**语义层**（H3 认为这里该有个名牌），不是"你让它写字"。
>
> ✅ **处置**（按有效性排序）：
> 1. **换 seed 重跑**（泄漏是概率性的；本轮 36/61 各换 seed 后复检）
> 2. 给镜 61 补上守护句（它原本**完全没有**文字守卫 —— 已补）
> 3. **后期兜底**：`_subbox_coords.py` + `delogo` 抹除（§6.6b 的既有流程）

> ★★★ **给全片的教训**：**每轮重跑后必须重跑 `_scan_text_rows.py` + 读图复核**，
> 因为**换 seed 既可能修掉旧泄漏、也可能引入新泄漏**。字幕泄漏与音频缺陷一样，
> 是**概率性副作用**，不能靠"我这次没动画面"来豁免。

#### 6.10.11 ★★★ 事故复盘：**H3 把训练语料的「AI 生成水印」画成了道具表面文字**（2026-09-18）

> 本轮起因：用户要求「一个镜头一个镜头地检查」。逐镜读**联系表**时，

| 字 | `豆包AI生成`（六个字，**清晰可读**，8/8 帧全中） |

**为什么此前的两道闸门都漏了**

| 闸门 | 失效原因 |
|---|---|
| `_scan_text_rows.py`（字幕泄漏） | 只扫 **0.76–0.96H 的字幕带**；水印在 **0.72H**，**差一点就出了带** |

**根因（★ 最有价值的一条）**

> 镜 18 旧 prompt 是**全片唯一没有文字禁令的镜**（姊妹镜 15/16 都有守护句），

> ⇒ **特写道具 + 无文字禁令 = 模型自由发挥表面纹理**，
> 而"表面文字"正是最容易被翻出来的纹理（§6.9 同源：H3 走**文本渲染**路径）。

1. 新增常量 **`NO_TEXT_SCENE`** —— 与 §6.9 的"泛泛禁令"不同，它**穷举文字载体**：
   设备外壳 / 机身 / 屏幕 / 桌面 / 墙面 / 纸面 / 衣物 / 道具 / 贴纸 / 标签 /
   商标 / 丝印 / 印刷 / 落款 / 条码，并**明确点名**「没有『AI 生成』一类的角标」。
2. 明写设备外观为"**磨砂金属、无任何印刷/丝印/贴标**"。
3. **换 seed**（9631 → 9633）：水印是采样期决定的，换 seed 才能换掉。
4. 产物：`18_sicheng_presses_start_button_00005_.mp4`（字幕带扫描 0 命中）。

> ⚠️ **纪律**（同 §6.10.7）：`NO_TEXT_SCENE` 只说「**画面里不要有什么**」，
> 不说「你（模型）不要做什么」—— 后者会被当成台词念出来（§6.10.9 根因②）。

#### 6.10.12 ★★★ 事故复盘：**H3 自发补全「场景应有的 UI 文字」**（镜 104 车厢 LED 屏，2026-09-18）

> 与 §6.10.11 同日发现、**根因不同**，单独列出。

**现象**（镜 104 `zhong_walks_away_into_night`，全景车厢）

| 位置 | 内容 |
|---|---|
| 车厢顶部 **LED 信息屏**（约 0.04–0.14H） | 红色伪汉字「**驩 忻苜鑧**」+ 绿色「**用**」+ 彩色小图标 |
| 端墙**金属告示牌** | 同样带伪文字行 |

**根因**

> 镜 104 是「**全景车厢** + 无文字禁令」。H3 对"高铁车厢"这个概念有强记忆，
> **它不知道要留白，就把车厢"应该有的"公告信息全补上了**。
> ⇒ 这不是"抄错参考图"，而是**概念补全（concept completion）**：
> 提到某个场景，模型会自动补上该场景的典型元素 —— 包括**信息屏、报站屏、号牌、告示牌**。

**与 §6.9 / §6.10.11 的区别（重要）**

| 节 | 触发源 | 载体位置 |
|---|---|---|
| §6.9 | **我们主动要求**写校名 | 我们指定的位置（墙面） |
| §6.10.11 | 训练语料的 **AI 水印**被翻出 | 道具表面（机身） |
| **§6.10.12** | **场景概念的自动补全** | **场景"该有 UI"的地方（车厢顶部/端墙）** |

**⇒ 对策：禁令必须「点名场景里的文字载体」，不能只写"不要出现文字"**
