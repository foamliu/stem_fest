## 2.5 合影参考图（`_group/`，R2V 多人镜的硬前提）

R2V 只有 **2 个参考图位** ⇒ ≥2 人的镜头（本项目 **44 镜**，去重后 **20 种组合**，清单见 `OUTPUT/_cast_per_char.txt`）
必须先把该组合的人合成到**一张**图里。做法（2026-09-13 定，可复现）：

```
① 数值拼图：把组合里每个人的**单人定妆照**拼成 2×2（或 1×N）网格 → OUTPUT/_diag_group_montage.py
② LongCat 合成：image = 该拼图，prompt 写"合成到同一场景 + 必须正好 N 个人 + 不要带分格线"
   （seed 固定；megapixels 1.5）
③ 核查：① 人数对不对（多选一，3 次一致）② 是否还像拼图（多选一）③ 无 0 空谷的列/行剖面
④ ⚠️ 仍须**人工目视**确认"甲乙丙丁有没有混脸"（视觉模型对"像不像"不可靠）
```

## 3. 固定 seed 台账（生成后回填）

同一角色跨镜头**必须固定 seed**，否则造型漂移。第一次用 `image_edit_longcat` 生成分镜图时
把工具返回的实际 seed 记在这里，后续镜头复用。

> ⚠️ **造型基串的铁律**（2026-09-12 立）：**只写定妆照里客观可见的稳定特征**
> （发型发色 / 服装款式与颜色 / 眼镜 / 配饰）。**禁止**写体型、胖瘦、脸型、年龄感 ——
> 把"偏胖"改成"偏瘦"**同样是改外形**，正确做法是**这类形容词一个都不写**（形象由定妆照图承载）。
> **正确流程**：**先用本地视觉模型（`qwen3.5`）读一遍定妆照**，把读到的特征写成基串 ——
> 下表的 7 行即由此得出。**让定妆照说话，不要让剧本文字说话。**
