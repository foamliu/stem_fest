## 6. 参考图与"像不像"的坑（★ 2026-09-12 镜 15 实验结论，全项目适用）

### 6.1 输出尺寸 = 参考图缩放后的尺寸（`megapixels` 改不了画幅）

工作流的图是：
`LoadImage → ImageScaleToTotalPixels(megapixels) → ├ TextEncodeQwenImageEdit(正/负) ├ VAEEncode → KSampler.latent_image`

实测 4/4 吻合：`2048×1152→1360×768`｜`2304×1728→1184×880`（4:3，**不能当首帧**）｜`3072×1728→1360×768`｜`2304×1296 + 1.5MP→1680×944`。
→ **要 16:9 首帧，参考图就必须是 16:9**；`megapixels` 只能改总像素，改不了构图比例。

### 6.2 `KSampler.denoise = 1.0` 意味着"参考图只是条件，不是底图"

初始 latent 是纯噪声、参考图像素内容被丢弃，它只剩两个作用：① 决定输出画幅/尺寸；② 经 qwen2.5-vl 编码成 token 参与条件。
→ **构图 / 景别 / 人物在画面里的大小，100% 由 prompt 文字决定。**
这是"改了很多版 prompt、guidance、参考图裁剪却都不像"的主因：**脸的大小一直由文字决定，而文字里从来没有景别约束**。

### 6.3 实测"脸高"账（位置法，3 次取中位数）

| 版本 | 参考图 | megapixels | 输出尺寸 | 输出画面脸高 |
|---|---|:--:|---|---:|
| v09 | `closeup_v01`（4:3 单人） | 1.0 | 1184×880（4:3 ❌） | 132 px |
| v10 | `closeup_v01_16x9`（**补边**） | 1.0 | 1360×768 | 138 px |
| **v11 ★ 定版** | `closeup_v02_16x9`（**整宽裁**） | **1.5** | 1680×944 | **255 px** |

- 判读：**< 150 px 基本不可能像本人；200–300 px 可用；> 300 px 理想。**
- 参考图侧"模型能看到多少"：三视图整张 **112 px ❌**｜16:9 补边 255 px｜4:3 单人 294 px｜**整宽裁 16:9 = 416 px ✅**
- 结论：**瓶颈在输出景别，不在参考图分辨率**。先写死景别，再谈参考图。

### 6.4 补边 ≠ 无损

"最外侧 6 列拉伸"补出来的 2×384 px 竖带是非自然纹理，模型会当成画面元素。**能整宽裁就别补边。**

→ **静默失败**：工具照常返回 `ok:true` + 文件名。**必须以像素验收**（`np.asarray(im).mean() == 0` 即废）或看体积（正常 ≈1.5 MB）。
→ 目前**不要用 FireRed**；待排查方向：`qwen_image_vae` 与 `CLIPLoader(type=qwen_image)` 的搭配、`CFGNorm`、`ModelSamplingAuraFlow(shift=3.1)`。

### 6.6 本地视觉模型（qwen3.5）不能做"像不像"的二选一

`OUTPUT/_vision_report3.txt`：正序二选一选 **v07**（三视图为参考），倒序二选一选 **v08**（头肩裁切为参考）——**同一问题换个顺序结论就相反**（位置偏置）。

- ✅ 可用：单图**描述式**核查；"头顶/下巴距上边缘百分之几"这类**位置问题**（3/3 一致）
- ❌ 不可用：A/B 排序、绝对相似度打分、直接问"脸占画面百分之几"（同一张图会 35%/45% 乱跳）
- **"像不像"最终必须人眼定。**
