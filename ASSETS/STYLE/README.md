### 一句话风格

**超写实影视级真人质感**（8K 专业人像摄影 / 真人电影海报级精修）。
**不是**二次元、**不是** CG 数字人、**不是**迪士尼/皮克斯式卡通 3D。

### 正向风格后缀（所有出图 prompt 都应带上）

```
8K 超高清专业人像摄影质感，真人电影海报级精修；真实皮肤纹理与毛孔，柔和自然，不做过度磨皮；
影视级 PBR 渲染，4K 材质纹理；低饱和高对比度，色调统一、无偏色；
影视级柔光布光，光线均匀、层次清晰；画面干净、适度写实；
绝对无二次元插画感、无 CG 数字人感、无塑料假人感
```

### 负向风格后缀（**必须加**）


### ⚠️ 借用原模板时**必须裁剪**的部分（原套装是给成人女主的）

原模板含大量**成年女性**专属描述，**不能照搬到 13 岁初中生**：

| 原模板内容 | 我们的处理 |
|---|---|
| 超大杏眼、上下睫毛极长卷翘且根根分明 | ❌ **删除**（未成年人不适配，且是浓妆感） |
| 橙粉/豆沙色水光唇釉、脸颊粉橘色腮红、鼻尖小面积高光 | ❌ **删除**（化妆品描述） |
| 女总裁西装 / 珍珠耳钉 / 低盘发 / 职场发 | ❌ **删除**（场景不符） |
| 鹅蛋脸、轮廓偏窄、面部留白少、下颌线纤细 | ⚠️ **只保留"东方面孔"的取向，不写具体脸型**（见下方铁律） |
| 真实皮肤纹理、毛孔质感、柔和自然磨皮 | ✅ **保留** |
| 8K / 海报级 / PBR / 4K 材质 / 低饱和高对比 / 柔光 | ✅ **保留** |

> ⚠️ **与「定妆照 = 外形唯一权威」铁律的关系**：本风格后缀**只描述渲染质感与色调**，
> **不得**反过来规定人物的胖瘦、脸型、五官尺寸 —— 人物外形一律由定妆照承载。
> 需加"东方审美"取向时，写法是**否定式**（"不欧美化、不卡通化"），而不是**规定具体脸型**。
