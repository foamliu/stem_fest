## 0. ★★★ 给 AI Agent 的第 0 条规则：**你的基模本身就是视觉模型**

> **由来（必读）**：2026-09-15 修「镜 1 校名乱码」时，Agent 连续三次**绕远路** ——
> 先写脚本量化像素、再假设「参考图字太小所以抄错」、又想去调本地 VLM / 外部 Vision API，
> 而**正确做法从一开始就是：把图读进来，自己看**。这是本仓库最贵的一次时间浪费。
> **此节存在的唯一目的：以后不要再犯。**

| 事实 | 含义 |
|---|---|
| **基模自带视觉（vision）能力** | 工具 `read_files` 传入 `.png/.jpg/.jpeg/.webp` **会直接把图像喂给模型**。你**看得到**画面内容。 |
| **看到 = 第一手证据** | 你亲眼看到的，**优先级高于**任何脚本/启发式推断；也**不低于**数值法（两者互补，不是替代） |
| ★ **默认首选：先读图** | 任何「画面里有什么 / 对不对 / 哪里怪」的问题，**第一步就是读图**，不要先写脚本 |
| ⚠️ 额度 | 实测 ≈ **7 张/会话**，超出后**静默丢弃**（不报错！）⇒ 见下方省额度三条 |
| ⚠️ 弱点（真存在） | 低对比度小字、乱码、**逐字精确**、任何**数值**（相似度/覆盖率/响度）—— 见 §4.5 E |

**❌ 明确禁止的「绕远路」行为**（2026-09-15 实测全都没必要）

| 绕路做法 | 为什么错 | 正确做法 |
|---|---|---|
| 为「看清画面里写了什么」去写像素分析脚本 | 你能直接看，脚本只是**间接**证据且易误判（`_detect_text.py` 实测误报 3/4） | **先 `read_files` 读图** |
| 去调 `ollama` / 本地 VLM / 外部 Vision API 做「读图」 | 你自己就有视觉；外部 API 还要 key（本次 401） | **先 `read_files` 读图** |
| 从「缩略图/裁剪小图」上推断全局 | 裁剪会丢上下文，容易得出错误结论 | 读**原图**；需要细节时先拼**一张大对照图**再读 |
| 靠猜「大概是因为 X」下结论 | 2026-09-15 就因此把根因判错一轮 | 读完图，**说清「我看到了什么」**再下结论 |

**✅ 省额度的三条正解**（额度是真约束，但仍不该绕路）

1. **大而少**：做一张 **montage / 联系表**（1 张图塞 6 镜 × 4 帧）再读 —— 见 `OUTPUT/_subtitle_audit.py`
2. **先缩到 ≤1024 px**：`OUTPUT/_view.py`
3. **一次问清**：读图前先想好「我要从这张图判断哪几件事」，避免反复读同一张

> 📖 与本节配套的能力边界（能读什么/读不准什么）、环境区分、三条看图路优先级 → **§4.3 与 §4.5**。

### 4.2 H3 出视频与「参考图」照抄参数

| 参数 | **必须用** | 说明 |
|------|:---:|---|
| `steps` | **4（静态/单人/对话镜）/ 10（角色镜抽卡）/ 20（环境剧变镜）** | ⚠️ **不是一刀切**；MCP 签名默认值 `20` **不是配方**。<br>耗时（1056×608）：`4 步 ≈ 3.4 分` · `10 步 ≈ 9.5 分` · `20 步 ≈ 18–26 分`（近线性）<br>★ 镜 4「纸飞机掠过校园」实测 `4 步 ❌ → 10 步 ❌ → 20 步 ✅`（航拍跟拍、画面持续剧变） |

| `aspect_ratio` | `"16:9 (Widescreen)"` | |
| `duration` | 该镜时长（**照抄** `storyboard.md` 时长列） | `17k+5` 量化后实际播放多 0.04–0.58 s ⇒ **`6s` 实际比 `5s` 贵 1.41 s**，别随手写 6s。<br>换算表 / 定长规则 / 语速表 → `storyboard.md`「时长怎么定的」；公式见 §6.1 #13 |
| `ref_image_1` | 角色 / **对话双方合影** → `<Picture 1>` | 竖版头肩特写可直接用，**不必**裁 16:9 |
| `ref_image_2` | 该镜场景图 → `<Picture 2>` | 无角色镜走 `t2v` |
| `prompt` | `CUT 1:` + **景别**（照抄 `storyboard.md` 的景别列）+ 动作 + `Audio:` 台词原文 | 环境音不一定生成，见 §4.4；一镜一个主景别，定义见 storyboard「景别列读法」 |

**★ 参考图规则（2026-09-13 修订：按"在场人数"给图）** ——
**画面里应该出现几个人，参考图就必须含几张脸。** 只给说话人一张脸，其余人会消失、背景空荡。

| 画面里该有 | 参考图 |
|---|---|
| **4 人** | **四人合影**（`four_students`） |
| **2 人**（一对一对话） | **二人合影**（按组合拼版） |
| **1 人**（特写/反应镜）但场景里还该有别人 | **单人定妆照 + 四人合影**（双图位） |
| 确实只有 1 人、无背景人物 | 单人定妆照 + 场景参考 |
| 纯场景（无人） | 场景参考，走 T2V |

> ⚠️ **场景参考图不要用空教室**（模型会优先渲染空背景，人物像贴上去的）；面部特写镜例外，单人照即可。

### 4.4 ★ 音频三层分工（2026-09-13 定案）

**H3 只生成"可辨认的台词"，一切氛围声都在后期铺。**

| 层 | 内容 | 谁来做 |
|:--:|---|---|
| **L1 台词** | 角色的**明确台词**（有原文、要对口型） | ✅ **H3**（只此一项） |

### 6.4 ★★ **prompt 禁止写「元信息」**（写进画面描述会被渲染成字幕）

**事故（2026-09-14 镜 91）**：prompt 写了舞台指示
> 「眼神很深、表情看不出情绪，**像在消化一件很难立刻接受的事**」

成片画面底部**真的出现了这行中文字幕**。原因：模型无法表演「像在消化…」这种
**内心状态 / 镜头用意**，它能做的只有"把这句话显示出来"。

**事故二（2026-09-15 镜 5 / 镜 19）—— 比镜 91 更隐蔽**：连**否定式指令**也会被渲染。
- 镜 5 底部字幕「本镜不要生成任何可□旁白」← 来自 `NO_SPEECH` 常量（当时是「本镜不要生成任何…」）
  <br>⚠️ `□` 处**逐字读不准**（两个脚本分别记成「可语午白」「可口旁白」）⇒ 印证 §4.5 E：判"多了字"可以，判"多了什么字"要靠 OCR
- 镜 19 底部字幕「全镜高适」← 疑似同类幻觉（同样存在逐字不确定性）

⇒ 根因统一为：**prompt 里出现"对模型说的话"**（本镜 / 不要生成 / 只允许 / 若画面…），
H3 分不清"指令"与"台词"，一律当词句输出。
📌 **对策**：`NO_SPEECH` 已改成正向音景（见 §4.4）；全片 prompt 用脚本扫一遍（见下）。

| 写法 | 判定 |
|---|:--:|
| ✅ 摄影机拍得到的：动作、表情、景别、光线、环境、人数、衣着 | 安全 |
| ❌ **比喻式内心状态**：像在…／仿佛…／像是…／显得… | **会被画成字幕** |
| ❌ **镜头用意**：暗示…／表达…／说明…／观众要读到…／这是情绪高点 | **会被画成字幕** |
| ❌ **镜头编号指代**：本镜／该镜／这一镜 —— ⚠️ **`NO_SPEECH` 里的「本镜不要生成…」也曾被豁免，2026-09-15 实锤它照样被渲染成字幕 ⇒ 豁免取消，改正向音景（§4.4）** | **会被画成字幕** |

**修法**：改写成可见的物理表现。
```
✗ 像在消化一件很难立刻接受的事
✓ 面无表情地沉默了几秒，喉结动了一下
```

**⑧ ★★★ 2026-09-16 重大根因：`strip_late_audio()` 吃掉 `\n`，禁令与台词被压成一行**

> **这条推翻了 ① 里「R3 是充分条件」的结论——R3 本身没错，但它被提交环节静默破坏了。**

**现象**：8 个泄漏镜套完 R1–R4 配方、`--verify` 8/8 通过后**重跑，字幕依旧**
（镜 14 逐帧对比：新旧两版同一位置同一文本 `硬硬找补` / `我上次竞选科技之星`，8/8 帧仍在）。

**根因**：`strip_late_audio()` 旧实现是

```python
for sent in _re.split(r"(?<=[；。])|\n", text):   # ← \n 被当作分隔符
    if LATE_MARK in sent: continue
    out.append(sent)
return "".join(out).strip()                        # ← 无条件 join，\n 就此丢失
```

切句时 `\n` 当分隔符、join 时**不还原** ⇒ 多行 prompt 被**压成一整行**。
后果：`Audio:` 前缀所在句含 `（后期）` 被整句剔除，**禁令句与台词句失去段落隔离**，
H3 把整串当同一条指令，禁令对台词失去约束。

**证据链（可复现）**：

```powershell

```

坏版本（重跑前，全部挤成一行）：

```
…slow dolly in）。★ 全画面不得出现任何可读的文字、字幕或符号。男生嘴硬地说：我上次竞选科技之星，就输在少说了两句。
```

修复后（3 行清晰分离）：

```
行1: CUT 1: 近景半身镜头。…镜头缓慢向前缓推（slow dolly in）。
行2: ★ 全画面不得出现任何可读的文字、字幕或符号。
行3: 男生嘴硬地说：我上次竞选科技之星，就输在少说了两句。
```

**修法**：改为**按行处理、保留换行**（6 个 act 脚本 `strip_late_audio()` 已同步）：

```python
lines = []
for line in text.split("\n"):
    kept = [s for s in _re.split(r"(?<=[；。])", line) if LATE_MARK not in s]
    lines.append("".join(kept))
return "\n".join(lines).strip()
```

**⑥ ★★ 本轮第 5 个隐性坑：长镜 + 20 步 = 必 OOM（镜 99 实测）**

| 项 | 内容 |
|---|---|
| 现象 | 镜 99 用 `0.6 MP + 20 步` 直接 `torch.OutOfMemoryError`（节点 `SamplerCustomAdvanced`） |
| 根因 | 16GB VRAM 的**帧数临界点**：`9s → 226 帧`能过（镜 97 ✅），`10s → 243 帧`就爆 |
| 修法 | 单镜降到 `--mp=0.4` 跑通（显存余量 13 GB），再**事后恢复到 1056×608** |
| ★ 关键 | 降 mp 会改分辨率（864×480），若不恢复，`_concat_video.py` 会检测到**规格不一致**，回退成「**全片 126 镜重转码**」—— 为一镜损失整片画质 |
| 工具 | 新增 `_upscale_shot.py`：**只**把这一镜用 lanczos 升到 1056×608 |
| ⚠️ 注意 | 它是**恢复规格**不是"真超分"（864→1056 只有 1.22x，细节不会凭空长出来）。要真超分需另配 ESRGAN 类模型 |
| 帧数守恒 | 升分后**帧数必须不变**（243 → 243），否则拼接会错位。`_upscale_shot.py` 内置该检查 |

> **帧数量化公式**（供核对，别再算错）：
> `H3 内帧 = ceil(秒 × 24)` → `k = ceil((内帧 − 5) / 17)` → **`实际帧 = 17k + 5`**
> 例：9s→216→k=13→**226 帧**；10s→240→k=14→**243 帧**；5s→120→k=7→**124 帧**。

| 1 | **凡是"对模型说的话"，一个字都不能放进 prompt** | · `NO_SPEECH` 否定式指令 → 渲染成**画面字幕**（§4.4）<br>· `ONLY_THIS_LINE` 否定式清单 → 被**念成台词**（本节）<br>· 「本镜不要生成…」→ 渲染成画面字幕（镜 5/110） |

> ✅ **正解句式模板（照抄即可）**

> ```

**★★★ 本轮最重要的三条发现**

| # | 发现 | 证据 | 正解 |
|:-:|---|---|---|
| **①** | **`NO_SPEECH` 里的\"听不清任何词句\"会诱发 H3 编造语音** | 白屏日记卡镜 46/74/105 **本应零台词**，却分别念出「大妹子。」「谁了？」「嗯。」<br>它们的 Audio 都写着：`远处零星的人声杂音，听不清任何词句。` | **"听不清 X" ≠ "没有 X"**。把整个人声描述换成**物理声源**：<br>`远处有节奏的机械轰鸣与低频震动，持续而平稳。` |
| **②** | **`Audio:` 段里的舞台指示会被念出来** | 镜 97 的 Audio = `他平静地说：一九五九年，…`<br>ASR = 「**他平静地说：**一九五九年，…」 | 把**表演提示移到画面描述**（H3 用画面演语气），Audio 段只留 `他说：<台词>`。<br>全片 **39 处** `X地<动词>：` 已统一降级（`_fix_stage_direction.py`，可重复执行） |

**闸门升级（本轮新增 6 条）**

| 新增规则 | 拦截对象 |
|---|---|
| `听不清任何词句` / `人声杂音` / `模糊的人声` | 音景免责声明（会诱发编造语音） |
| `没有说出台词` | 语音元词汇 |

| `不重复[：:]` / `只说一[遍句]` / `说完就停` | **Audio 里的行为约束**（会被念出来，第 4 次复发） |

#### 6.10.10 ★★★ 事故复盘：**字幕泄漏检测器失效 + H3 把"喊出的专有名词"烧成字幕**（2026-09-17）

> 本轮**最严重的一次"验证工具本身失效"**：全片扫描报 `0/126 干净`，
> 但**抽帧读图后发现镜 36 画面里赫然烧着「继光哥」「你听见没」**。
> 这是 §6.6/§6.7 的**再犯**，且暴露了**闸门本身的三代缺陷**。

**第一部分：检测器为什么失效（三轮演进，每轮都被实测打脸）**

| 版本 | 判据 | 结局 |
|---|---|---|
| **v1** | 「亮像素中"紧贴暗像素"的比例 ≥ 0.55」 | ⛔ **漏检镜 36**。那是**夜间暗场**：`dark` 掩膜近全屏 ⇒ dilation 后 halo 也近全屏 ⇒ 比例被稀释到 0.30。**该判据在暗场必然失效** |
| **v2** | 「滑动窗 + 列投影离散段数 ≥4 + 平均字宽 ≤6%」 | ⛔ **误报 96/126**（几乎全片）。把**人脸高光、牙齿、白领口、桌面反光**全算了进去 —— 这些同样是"多个窄亮块横向排列" |
| **v3** | v2 + ①近中性白（`min(R,G,B)≥205 且 |R−B|≤14`）②仅在 **0.76–0.96H** 带内 ③**连通块拓扑**（`_blobs`：块数 ≥8 且最大块 <40% 总面积） | ✅ 7/126 候选 ⇒ **读图复核后真泄漏 2 镜** |

> ★★ **v3 的关键是"连通块拓扑"**：列投影（横向有没有亮像素）对**大色块**与**字形**是一样的；
> 但连通块完全不同 —— **字形是"很多小岛"，脸颊/额头是"一片大陆"**。
> 这条判据把镜 02（妈妈明亮的脸）与镜 60（暖色高光）从命中里剔除了。

> ★★★ **方法论铁律（比判据更重要）**：
> **扫描器只能把候选缩到个位数，"到底有没有字"必须读图确认。**
> `_scan_text_rows.py` 的注释里写着"这是筛查器不是判官"，但**本轮我一度把它当判官用了**
> （看到 `0/126` 就以为干净）⇒ 差点放过真泄漏。
> ⇒ 固化为 `OUTPUT/_textrows_verdict.py`（**人工复核裁定表**）+ `_selftest_textrows.py`（**正负例自测**）：
> · 正例（应命中）：镜 36 四帧 · 负例（不该命中）：镜 02 脸 / 镜 60 高光 / 白条带
> · **检测器任何改动都必须先过自测（4 通过 / 0 不通过）**，否则不许用来下结论。

**第二部分：真泄漏只有 2 镜，根因是"喊出的专有名词"**

| 镜 | 烧进画面的字 | 原因 |
|:--:|---|---|
| **36** | 「**继光哥**」「你听见没」 | 台词 `小战士喊：黄继光哥！你听见没！打赢了！` |
| **61** | 「**袁隆平爷爷**」 | 台词 `男生脱口而出：袁隆平爷爷，您……` |

> ★★ **共同点：泄漏的都是台词里"被喊出来的专有名词"** —— 而且**只有名字那几个字**，
> 后面的正文（「你听见没」是唯一例外）没被烧。
> ⇒ 定性：**H3 把"喊出一个名字"理解成了"给这个人打字幕名牌"**。
>
> ★ 关键反证：**镜 36 的 prompt 里本来就有很强的守护句**

> **照样泄漏** ⇒ 再次确认 §6.7 的结论：**"禁止写文字"的守护句挡不住**，

### 6.9 ★★ **画面里的招牌/校名：H3 会"自由发挥"编字（镜 1 案例，2026-09-15）**

> **这是 §6.7 的一个特例，但根因不同，单独列出。**
> §6.7 是「我们**主动要求** H3 写字，它写错」；本节是「我们只想要个**场景**，
> 却因为一句『校牌清晰可见』把 H3 引上了写字的路，**它写出的字与参考图毫无关系**」。

**现象**（镜 1 `girl_mother_at_school_gate`，旧版 prompt）

| | 参考图 `school_gate_wide_v02.png` | H3 生成帧 |
|---|---|---|
| 中文 | `上汇实验学校`（**门柱竖排小铭牌**，字高约 6–15 px） | `汇月?舱学校`（**墙面横排大字**） |
| 英文 | `Shanghai Experimental School`（3 行，极小） | `Aue…ental Scoule`（`Scoule` 拼错） |
| 位置 | 门柱侧面 | **墙面正中**（参考图该处本是**竖条纹木板**） |

**★ 关键证据（推翻"抄错"假说）**

1. 生成帧里**中文与英文的意思都对**（"汇…学校" / "…ental Sc…ol"），
   ⇒ H3 **知道**"这里应该有校名"，是**在按语义编字**，不是在描摹参考图
2. 同一镜 **0.2 s 与 2.8 s 两帧的乱码字形完全一致** ⇒ 是一次成型，非逐帧抖动
3. 乱码**换到了参考图没有文字的墙面上**，且改为横排大字
   ⇒ **H3 把"校牌清晰可见"理解成"要画一块显眼的招牌"，于是新造了一块**

**⇒ 真正的根因**：**H3 对画面内文字走的是"文本渲染（text rendering）"路径，
该能力对中文本身就不可靠**；参考图里字的大小只决定"有没有参考"，
**不决定成败**（即使参考图字够大，`Scoule` 这类英文拼写错误照样出现）。

**⇒ 对策（★ 不要试图"让 H3 把字写对"）**

| 做法 | 评价 |
|---|:--:|
| ★ **不要求画面出现任何文字** —— prompt 只描述**建筑特征**（「门柱上有一块小小的竖排铭牌与红色圆形校徽，仅有装饰性色块，看不到可辨认的笔画」），校名由**后期贴字**保证 | ✅ **正解** |
| ★ 显式加一句「全画面不得出现任何**可读的文字/招牌字样/英文单词**」 | ✅ 有效（与 §4.4 `NO_SPEECH` 同思路：**正向描述场景，不逐字要求文字**） |
| prompt 里**明示正确校名**让它照写 | ❌ 无效：H3 渲染中文是**概率性**的，给对条件也不保证对（英文还会拼错） |
| 换更大更清晰的参考图 | ❌ 基本无效：见上「关键证据 3」 |
| 后期 `delogo` / 贴字覆盖 | ✅ 兜底方案（`OUTPUT/_burn_cards.py` 同思路） |

**已修复的写法**（`OUTPUT/_diag_act0_plane.py` TASKS[1]，2026-09-15）
```python
# 旧：校牌清晰可见、完整入画；          ← 主动邀请 H3 写大字
# 新：门柱上有一块**小小的竖排铭牌与红色圆形校徽**（仅有装饰性色块与图案，
#     **看不到任何可以辨认的字母或笔画**）；
#     ★ 全画面**不得出现任何可读的文字、招牌字样、英文单词或字幕**；
```

> 📌 **推广**：全片凡是画面里**天然有文字**的地方（校名 / 门牌 / 报纸 / 标语 / 广告），
> 一律按本节处理：**只描述"有块牌子"，不要求"牌子上写着什么"**。
