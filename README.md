### 4.2 看图与验收（★ 2026-09-13 更新：主模型已能直接看图）

**① 主模型（我）现在可以直接读图**（此前不支持，用户已更换底座模型）。但有一条硬限制：

> ⚠️ **每条会话的图片投递额度有限**：实测同一会话读到第 **~7 张**之后，**后续图片会被静默丢弃**
> （连 **6.8 KB** 的小图也丢，工具只回 "media omitted: invalid or exceeds size limit"；**新开会话即恢复**）。
>
> **省额度三招**：
> · **只读最关键的那几张**，读完立刻下结论，不要重复读同一张；
> · 大图先用 `OUTPUT/_view.py` 生成 **≤1024 px JPEG 预览**（超大图会被 read 工具直接拒收）；
> · **把多张拼成一张 montage / 对照图再读** —— 一张图承载 N 条信息，是最省的用法。

**② 本地视觉模型 `qwen3.5:latest`**（兜底 / 可脚本化批量核查）：

| 项 | 值 |
|----|-----|
| ★ 可用 | **`qwen3.5:latest`** —— 9.7B / Q4_K_M / **262144 上下文** / Capabilities 含 **vision, tools, thinking**；**原生多模态**（视觉塔内建，非外挂 projector） |
| ❌ 不可用 | `llava:latest` —— 实测同一张图给出互相矛盾的答案 + 复读退化 |
| 服务 | `http://127.0.0.1:11434`（v0.34.0，监听 `0.0.0.0`，局域网可访问） |
| 模型库 | **`E:\ollama\models`** |
| 调用要点 | 必须 `"think": False`（否则 response 为空）、body 显式 UTF-8、图片缩到长边 ≤1024 |
| 完整代码与踩坑 | 见 **[ASSETS/README.md](ASSETS/README.md) §7** |

**已用它完成**：`SCENES/_school_raw/` 17 张学校照片的分类与用途推荐（15 秒跑完）。

> ⚠️ **能用 / 不能用**：**"多选一"分类**可靠（如"背景是室内还是稻田？"→ 3 次同答才算数）；
> **排序 / 打分 / "像不像"** 不可靠 —— 有位置偏置，正序与倒序会给出相反结论（实测踩过）。

**③ 数值法验收（图片额度耗尽时的首选，客观可复现）**

色调 / 亮度 / 饱和度 / 天空均匀度这类**可量化**指标直接算，比看图更硬、还能写进台账：

| 脚本 | 量什么 |
|------|--------|
| `OUTPUT/_diag_color_stats.py` | 整体与分区 RGB、饱和度、天空 std（均匀度）、土壁 G/R、亮部占比 |

   · 无角色（场景/道具/群像）→ z_image_turbo_t2i
   output_dir = OUTPUT/<段落>/frames
   ★ 验收：输出画面**脸高 ≥ 250 px**（位置法量，见 §7 末）
        ↓
③ 出视频 ★（音频在这一步就生成了，不要另做配音）
   · **有角色 → video_minimax_h3_r2v（★ 本项目唯一入选路线，2026-09-12 定案）**
              ref_image_1 = 该角色的 16:9 单人参考图      → prompt 里写 `<Picture 1>`
