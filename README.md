### 4.2 H3 出视频与「参考图」照抄参数

| 参数 | **必须用** | 说明 |
|------|:---:|---|
| `steps` | **4（静态/单人/对话镜）/ 10（角色镜抽卡）/ 20（环境剧变镜）** | ⚠️ **不是一刀切**；MCP 签名默认值 `20` **不是配方**。<br>耗时（1056×608）：`4 步 ≈ 3.4 分` · `10 步 ≈ 9.5 分` · `20 步 ≈ 18–26 分`（近线性）<br>★ 镜 4「纸飞机掠过校园」实测 `4 步 ❌ → 10 步 ❌ → 20 步 ✅`（航拍跟拍、画面持续剧变） |
| `megapixels` | **0.6** | → 1056×608；0.92(720p) **必 OOM**。要 1080p 生成后超分 |
| `aspect_ratio` | `"16:9 (Widescreen)"` | |
| `duration` | 该镜时长（**照抄** `storyboard.md` 时长列） | `17k+5` 量化后实际播放多 0.04–0.58 s ⇒ **`6s` 实际比 `5s` 贵 1.41 s**，别随手写 6s。<br>换算表 / 定长规则 / 语速表 → `storyboard.md`「时长怎么定的」；公式见 §6.1 #13 |
| `ref_image_1` | 角色 / **对话双方合影** → `<Picture 1>` | 竖版头肩特写可直接用，**不必**裁 16:9 |
| `ref_image_2` | 该镜场景图 → `<Picture 2>` | 无角色镜走 `t2v` |
| `prompt` | `CUT 1:` + **景别**（照抄 `storyboard.md` 的景别列）+ 动作 + `Audio:` 台词原文 | 环境音不一定生成，见 §4.4；一镜一个主景别，定义见 storyboard「景别列读法」 |

**★ 参考图规则（2026-09-13 修订：按"在场人数"给图）** ——
**画面里应该出现几个人，参考图就必须含几张脸。** 只给说话人一张脸，其余人会消失、背景空荡。

| 画面里该有 | 参考图 |
|---|---|
| **4 人** | **四人合影**（`four_students`） |
| **2 人**（一对一对话） | **二人合影**（按组合拼版） |
| **1 人**（特写/反应镜）但场景里还该有别人 | **单人定妆照 + 四人合影**（双图位） |
| 确实只有 1 人、无背景人物 | 单人定妆照 + 场景参考 |
| 纯场景（无人） | 场景参考，走 T2V |

> ⚠️ **场景参考图不要用空教室**（模型会优先渲染空背景，人物像贴上去的）；面部特写镜例外，单人照即可。

### 4.3 ★ 看图与验收（三条路，按优先级）

1. **主模型直接读图**（最快）—— ⚠️ 每条会话图片额度有限，实测读 **~7 张**后静默丢弃，**新开会话恢复**。
   省额度：只读关键的、大图先缩到 ≤1024 px（`OUTPUT/_view.py`）、**多张拼成 montage 再读**。
2. **本地 `qwen3.5:latest`**（可脚本化的批量核查）—— 用法与踩坑见 `ASSETS/README.md` §7。
   ⚠️ **跑批期间绝对不要调它**：常驻 5.5 GB 显存会把 H3 挤爆。
3. **数值法**（客观可复现，额度耗尽时首选）—— 用 PIL 现算：整图 RGB 均值 / 饱和度、
   局部四角取样（背景明暗冷暖）、土壁 G/R 比、天空 std、主体亮部占比。
   **脚本是可丢弃的**，量完即删，别囤在 `OUTPUT/`。

> 📖 三条路的能力边界与实测踩坑（额度、位置偏置、调色锁定的量化方法）→ `ASSETS/README.md` §7。

### 4.4 ★ 音频三层分工（2026-09-13 定案）

**H3 只生成"可辨认的台词"，一切氛围声都在后期铺。**

| 层 | 内容 | 谁来做 |
|:--:|---|---|
| **L1 台词** | 角色的**明确台词**（有原文、要对口型） | ✅ **H3**（只此一项） |
| **L2 环境声** | 风声 / 铁锹声 / 蝉鸣 / 稻浪 / 铁轨声 / 键盘声 / 炮响 / 纸张翻动 | ❌ 不用 H3 → **`ace_step_t2audio`** |
| **L3 群杂人声** | 学生交头接耳（"讨论声"、walla） | ❌ 不用 H3 → **`ace_step_t2audio`** |

> **为什么**（实测）：H3 把 `Audio:` 里的一切都当"有人要说话"处理，且**听不进去"多人说话"的语义**
> —— 只会产出一段单声道、无空间感、听不清内容的糊状人声（镜 9「讨论声渐起」已踩坑）；
> 环境声更直接：实测 H3 前后段 ≈ **−50 dB**（生不出来）。
> 📖 **L3 的实测指标与照抄配方 → `mcp_server/comfyui_tools.md`**（`ace_step_t2audio` 一节）。

**⚠️ 剧本文本纪律**：`音效：` 列里**禁写"讨论声 / 人声 / 说话声"**这类会被 H3 当台词的词
⇒ 改用显式标记 **`（后期）`** 后缀，生成脚本的 `strip_late_audio()` 会在拼 prompt 时
**自动剔除该整句**，只把 L1 台词交给 H3。三个生产脚本均已内置该函数并在 `run_shot()` 里调用。

**`NO_SPEECH` 文案**（无台词镜必须挂，否则 H3 会幻觉出人声 —— 实测镜 4 出"啊"、镜 5 出整句胡话）：
> 【本镜不要生成任何可辨认的语音或对白。只允许环境音与物件音；
> 若画面有人群，也只是听不清的杂音，不要生成任何词句。】

> 📖 **分层台词逐镜分布**（哪些镜有 L1、哪些是 `（后期）`）→ `storyboard.md` 各幕逐镜表「台词/音效」列。

## 5. 内容层面的铁律（★ 违反必出废片）

> 📖 **逐条事实与出处（性别 / 年龄 / 口音 / 稻田不是麦田 / 徐畅景不戴眼镜 / 选图标准 …）
> 一律以 `storyboard.md` §角色性格与定位 · §空间与时间逻辑总览 及各幕逐镜表为准，不在此复述。**

| 铁律 | 违反后果 |
|---|---|
| ★★ **定妆照 = 外形的唯一权威** | prompt 写体形 / 脸型 / 胖瘦 / 年龄感 → 生成结果会**真的变脸变胖**（镜 15 踩过：写"圆脸、偏胖"，实为瓜子脸） |
| ★ **全片风格 = 超写实真人质感** | 出图 prompt **必须带「风格后缀」**（唯一出处 `ASSETS/STYLE/README.md`）；**不是**卡通 3D / 二次元 / CG |
| ★ **写 prompt 用"外观描述"代替年龄数字** | 写"83 岁"会画出苍老；写"精神矍铄、面容紧致、不显老"才对 |
| ★ **分镜里的性格/印象描述不可当外形依据** | "胖胖的""说话慢"是性格写法，外形只能看定妆照 |
| ★ **能裁就别修** | 画面内文字/水印落在空白区时**直接裁掉那条带**最可靠；任何"拟合填充"都留伪影。<br>裁前量"可裁边界"：**文字下界 < 裁切线 < 主体上界** |
| ★ **"自动检测画面内文字"会误伤人脸** | 通用"深色小连通域 + 聚类"会把**发丝边缘**当文字。<br>正解 ＝ **先区域约束定位** + **强校验「框外像素与源图逐像素完全相同」** |

> ⚠️ **视觉年龄 ≠ 实际年龄**：袁隆平 1961 年实际 31 岁（"21–25 岁"读数是符合设定的青年形象）；
> 钟南山 2020 年实际 83 岁但本人显年轻 → **不要画苍老**。
> 📖 **素材侧其余约束**（全 ASCII 命名 / 跨格式哈希不可比 / 相似度阈值 / 三视图风险 / 同名 `(1)(2)(3)` 必比对）
> → `ASSETS/README.md`。

## 6. 已知坑与硬约束（都是实测踩出来的，别重犯）

### 6.1 ComfyUI / 工具侧

| # | 约束 | 说明 |
|:-:|------|------|
| 1 | ★★ **定妆照 = 外形的唯一权威；prompt 禁止改动外形** | 造型基串只能写**客观可见的稳定特征**（性别 / 发型发色 / 服装 / 配饰）。**严禁**写体型、脸型、胖瘦、年龄感。<br>**反面案例**：镜 15 prompt 写了"圆脸、偏胖"（定妆照实为瓜子脸）→ 生成结果**胖一圈、脸变圆** |
| 2 | **H3 `megapixels` ≤ 0.6** | 16GB VRAM 下 0.92 必 OOM；要 1080p 生成后超分 |
| 3 | **H3 R2V 最多 2 张参考图** | ≥2 人镜 ⇒ 必须**一张合影**。<br>★ **合影 = 程序拼版，不经图生图**（2026-09-14 定案）：`image_edit_longcat` 转过的合影**有些身份失真** ⇒ 用 `OUTPUT/_make_group.py` 拼版直接入库。做法见 §4.2 |
| 4 | **角色镜必须引用定妆照** | 否则每张脸随机变化，定妆照白做 |
| 5 | **上传不覆盖同名文件** | 同名存为 `名字 (1).png`。**换图后先删 `E:\code\ComfyUI\input\名字.png` 再上传** |
| 6 | **输出规格以 `ffprobe` 实测为准** | 不要相信注释里的分辨率 |
| 7 | **长任务用 `wait=False`** | 先拿 `prompt_id`，再用 `comfyui_get_result` 取回 |
| 8 | ★ **启批处理前先看清任务数；跑完确认进程退出 + 队列清零** | 曾发生：脚本实参是 8 个镜头却被当成 2 个，且**进程后台存活**，LongCat 首帧任务与 H3 视频任务在队列里**交替执行**，每个还要重载 11.96 GB 模型 ⇒ 纯浪费。<br>**纪律**：① 启脚本前 `--dry` 看清任务数；② 跑完用 `Get-CimInstance Win32_Process` 核进程、查 `/queue` 与 `/history`；③ 不同 batch 输出前缀要可区分 |
| 9 | ★ **清队列姿势** | 删**排队中**：`POST /queue {"delete":[prompt_id]}`；<br>中断**正在执行**：先 `POST /interrupt`（空 body）再删队列 —— **只发 delete 删不掉 running 那个**；<br>清历史：`POST /history {"clear":true,"delete":[id,…]}` |
| 10 | ★★ **`steps` 按镜头类型选（4 / 10 / 20），不照抄签名默认值** | 见 §4.2。**耗时的真正决定变量是 steps × 帧数**，不是"模型比显存大" |
| 11 | ★ **跑批期间不要调 ollama 视觉模型** | `qwen3.5` 常驻 5.5 GB，会把显存挤到 76 MiB、功耗掉到 30 W。<br>用完必须 `Stop-Process -Id <llama-server PID> -Force`（`ollama stop` 会卡在 `Stopping...`） |
| 12 | ★ **H3 输出分辨率由 `ResolutionSelector` 反推** | `√(megapixels×1024²/(16×9))` 取 32 的整数倍：`0.6→1056×608`、`0.4→832×480`、`0.3→736×416`、`0.2→608×320` |
| 13 | ★ **帧数只能是 `17k+5`** | 公式 `max(5, round(时长×24)) + (5 - (max(5, round(时长×24)) % 17)) % 17`（`workflows/video_minimax_h3_r2v.json` 节点 131）<br>⚠️ 旧文写的「5s→136 帧 / 6s→136 / 7s→170」**是错的**，实测 `124 / 158 / 175` |
| 14 | **TTS `custom_speaker_name` 必须为空** | 仅在使用 `qwen3_tts` 时适用；该字段是音色 mixing 列表，填自定义名 → `ValueError` |
| 15 | **H3 不一定生成环境音** | 镜 15 实测：只念了台词，前后段 ≈ −50 dB ⇒ **环境音另做**（见 §4.4 三层分工） |

## 7. 推荐生产流程（逐镜）

```
① 查 storyboard.md 该镜「参考图提示」列 → 确定要什么素材
② 出分镜图：有角色 → image_edit_longcat；无角色 → z_image_turbo_t2i
   · image = 定妆照 / 合影（≥2 人一律用拼版合影，见 §4.2）
   · prompt = 景别（必须写死）+ 场景 + 表情动作 + 风格后缀（勿用文字描述长相）
   · seed = ASSETS/README.md §2「固定 seed」｜ megapixels = 1.5（→1680×944）
   · ★ 验收：输出画面脸高 ≥ 250 px
③ 出视频（音频这步一并生成，**不要另做配音**）
   · 有角色 → video_minimax_h3_r2v；无角色 → t2v
   · ref_image_1 = 角色/合影 → <Picture 1>｜ref_image_2 = 场景图 → <Picture 2>
   · prompt = `CUT 1:` + 景别 + 动作 + `Audio:`（L1 台词原文；环境声另铺）
   · 参数照抄 §4.2（尤其 steps）
④ 音频：片段内 L1 台词 → H3 prompt；L2 环境声 / L3 群杂 → ace_step_t2audio（见 §4.4）
        跨镜 BGM → 现成音源后期铺整段（版权标注见 storyboard.md）
⑤ 剪辑：按镜号拼接（相邻用尾帧/首帧衔接）→ 铺 BGM → 音量平衡 → 循环播放
```

> ⚠️ **改任何台词后必须重跑** `python OUTPUT/_diag_shot_duration_audit.py` —— 时长是按字数算出来的。

### 7.1 分批跑幕：照抄即可的命令

每幕一个独立脚本（**互不引用**，避免 NameError），产物落在对应 `OUTPUT/<scene>/video/`，
报告落在 `OUTPUT/_act<N>_<scene>_report.txt`。幕 ↔ 镜号 ↔ 脚本 ↔ 目录的对照表见 **§3**。

```powershell

py -3.10 OUTPUT/_diag_act1_trench.py --dry

# ② 跑全幕（后台，单条 3–26 分钟，整幕数小时）—— 必须后台，否则 30s 命令超时
Start-Process py -ArgumentList '-3.10','OUTPUT/_diag_act1_trench.py','--steps=10' `
  -RedirectStandardOutput OUTPUT/_act1_run.log -NoNewWindow

# ③ 抽查单镜（先用短镜验证管线，再放全量）
py -3.10 OUTPUT/_diag_act1_trench.py --steps=4 35

# ④ 跑完核对：进程已退出 + 队列清零（§6.1 #8）
Get-CimInstance Win32_Process -Filter "Name='py.exe'" | Select-Object ProcessId,CommandLine
py -3.10 -c "import json,urllib.request;q=json.load(urllib.request.urlopen('http://127.0.0.1:8188/queue'));print(len(q['queue_running']),len(q['queue_pending']))"
```
