## 0. ★★★ 给 AI Agent 的第 0 条规则：**你的基模本身就是视觉模型**

> **由来（必读）**：2026-09-15 修「镜 1 校名乱码」时，Agent 连续三次**绕远路** ——
> 先写脚本量化像素、再假设「参考图字太小所以抄错」、又想去调本地 VLM / 外部 Vision API，
> 而**正确做法从一开始就是：把图读进来，自己看**。这是本仓库最贵的一次时间浪费。
> **此节存在的唯一目的：以后不要再犯。**

| 事实 | 含义 |
|---|---|
| **基模自带视觉（vision）能力** | 工具 `read_files` 传入 `.png/.jpg/.jpeg/.webp` **会直接把图像喂给模型**。你**看得到**画面内容。 |
| **看到 = 第一手证据** | 你亲眼看到的，**优先级高于**任何脚本/启发式推断；也**不低于**数值法（两者互补，不是替代） |
| ★ **默认首选：先读图** | 任何「画面里有什么 / 对不对 / 哪里怪」的问题，**第一步就是读图**，不要先写脚本 |
| ⚠️ 额度 | 实测 ≈ **7 张/会话**，超出后**静默丢弃**（不报错！）⇒ 见下方省额度三条 |
| ⚠️ 弱点（真存在） | 低对比度小字、乱码、**逐字精确**、任何**数值**（相似度/覆盖率/响度）—— 见 §4.5 E |

**❌ 明确禁止的「绕远路」行为**（2026-09-15 实测全都没必要）

| 绕路做法 | 为什么错 | 正确做法 |
|---|---|---|
| 为「看清画面里写了什么」去写像素分析脚本 | 你能直接看，脚本只是**间接**证据且易误判（`_detect_text.py` 实测误报 3/4） | **先 `read_files` 读图** |
| 去调 `ollama` / 本地 VLM / 外部 Vision API 做「读图」 | 你自己就有视觉；外部 API 还要 key（本次 401） | **先 `read_files` 读图** |
| 从「缩略图/裁剪小图」上推断全局 | 裁剪会丢上下文，容易得出错误结论 | 读**原图**；需要细节时先拼**一张大对照图**再读 |
| 靠猜「大概是因为 X」下结论 | 2026-09-15 就因此把根因判错一轮 | 读完图，**说清「我看到了什么」**再下结论 |

**✅ 省额度的三条正解**（额度是真约束，但仍不该绕路）

1. **大而少**：做一张 **montage / 联系表**（1 张图塞 6 镜 × 4 帧）再读 —— 见 `OUTPUT/_subtitle_audit.py`
2. **先缩到 ≤1024 px**：`OUTPUT/_view.py`
3. **一次问清**：读图前先想好「我要从这张图判断哪几件事」，避免反复读同一张

> 📖 与本节配套的能力边界（能读什么/读不准什么）、环境区分、三条看图路优先级 → **§4.3 与 §4.5**。

### 4.2 H3 出视频与「参考图」照抄参数

| 参数 | **必须用** | 说明 |
|------|:---:|---|
| `steps` | **4（静态/单人/对话镜）/ 10（角色镜抽卡）/ 20（环境剧变镜）** | ⚠️ **不是一刀切**；MCP 签名默认值 `20` **不是配方**。<br>耗时（1056×608）：`4 步 ≈ 3.4 分` · `10 步 ≈ 9.5 分` · `20 步 ≈ 18–26 分`（近线性）<br>★ 镜 4「纸飞机掠过校园」实测 `4 步 ❌ → 10 步 ❌ → 20 步 ✅`（航拍跟拍、画面持续剧变） |

| `aspect_ratio` | `"16:9 (Widescreen)"` | |
| `duration` | 该镜时长（**照抄** `storyboard.md` 时长列） | `17k+5` 量化后实际播放多 0.04–0.58 s ⇒ **`6s` 实际比 `5s` 贵 1.41 s**，别随手写 6s。<br>换算表 / 定长规则 / 语速表 → `storyboard.md`「时长怎么定的」；公式见 §6.1 #13 |
| `ref_image_1` | 角色 / **对话双方合影** → `<Picture 1>` | 竖版头肩特写可直接用，**不必**裁 16:9 |
| `ref_image_2` | 该镜场景图 → `<Picture 2>` | 无角色镜走 `t2v` |
| `prompt` | `CUT 1:` + **景别**（照抄 `storyboard.md` 的景别列）+ 动作 + `Audio:` 台词原文 | 环境音不一定生成，见 §4.4；一镜一个主景别，定义见 storyboard「景别列读法」 |

**★ 参考图规则（2026-09-13 修订：按"在场人数"给图）** ——
**画面里应该出现几个人，参考图就必须含几张脸。** 只给说话人一张脸，其余人会消失、背景空荡。

| 画面里该有 | 参考图 |
|---|---|
| **4 人** | **四人合影**（`four_students`） |
| **2 人**（一对一对话） | **二人合影**（按组合拼版） |
| **1 人**（特写/反应镜）但场景里还该有别人 | **单人定妆照 + 四人合影**（双图位） |
| 确实只有 1 人、无背景人物 | 单人定妆照 + 场景参考 |
| 纯场景（无人） | 场景参考，走 T2V |

> ⚠️ **场景参考图不要用空教室**（模型会优先渲染空背景，人物像贴上去的）；面部特写镜例外，单人照即可。

### 4.3 ★ 看图与验收（三条路，按优先级）

### 4.4 ★ 音频三层分工（2026-09-13 定案）

**H3 只生成"可辨认的台词"，一切氛围声都在后期铺。**

| 层 | 内容 | 谁来做 |
|:--:|---|---|
| **L1 台词** | 角色的**明确台词**（有原文、要对口型） | ✅ **H3**（只此一项） |
| **L2 环境声** | 风声 / 铁锹声 / 蝉鸣 / 稻浪 / 铁轨声 / 键盘声 / 炮响 / 纸张翻动 | ❌ 不用 H3 → **`ace_step_t2audio`** |
| **L3 群杂人声** | 学生交头接耳（"讨论声"、walla） | ❌ 不用 H3 → **`ace_step_t2audio`** |

> **为什么**（实测）：H3 把 `Audio:` 里的一切都当"有人要说话"处理，且**听不进去"多人说话"的语义**
> —— 只会产出一段单声道、无空间感、听不清内容的糊状人声（镜 9「讨论声渐起」已踩坑）；
> 环境声更直接：实测 H3 前后段 ≈ **−50 dB**（生不出来）。
> 📖 **L3 的实测指标与照抄配方 → `mcp_server/comfyui_tools.md`**（`ace_step_t2audio` 一节）。

**⚠️ 剧本文本纪律**：`音效：` 列里**禁写"讨论声 / 人声 / 说话声"**这类会被 H3 当台词的词
⇒ 改用显式标记 **`（后期）`** 后缀，生成脚本的 `strip_late_audio()` 会在拼 prompt 时
**自动剔除该整句**，只把 L1 台词交给 H3。三个生产脚本均已内置该函数并在 `run_shot()` 里调用。

**`NO_SPEECH` 文案**（无台词镜必须挂，否则 H3 会幻觉出人声 —— 实测镜 4 出"啊"、镜 5 出整句胡话）

> ⛔ **旧版（2026-09-13 的"否定式指令"）已作废 —— 它本身就是污染源**：

#### 4.4b ★★ `ONLY_THIS_LINE`：**有台词镜**的「抑制额外人声」后缀（2026-09-17 新增，**已踩坑并修正**）

> 由来：用户反馈镜 7/14「**给 3/4 秒时间过多，导致前边合成多余语音**」。
> 与 `NO_SPEECH` 是**互补**关系：`NO_SPEECH` 管**整镜无台词**；
> `ONLY_THIS_LINE` 管**有一句台词、但 H3 在起势空档里又自己编了语音**。

⛔⛔ **第一版写法已作废（实锤失败，务必引以为戒）**

初版写的是"否定式清单"：

```
全程只有这一个说话人的声音，只有上面这一句台词，

**结果：H3 把这句指令本身当台词念了出来**（`qwen3_asr` 回读实得）：

| 镜 | ASR 实得 | 多出来的部分 |
|:--:|---|---|
| 7 | 你少自恋了，**只有上面这一句台词** | ⛔ 指令被念 |
| 13 | 你少说两句就不会。**只有上一句抬口** | ⛔ 指令被念（且字形糊） |
| 15 | 你输在轻敌，**全程只有这个外死的** | ⛔ 指令被念（且字形糊） |

> ★ **这与 §4.4 旧版 `NO_SPEECH`（"本镜不要生成任何可辨认的语音"）被渲染成画面字幕，

> **★★ 凡是"对模型说的话"，一个字都不能出现在 prompt 里。**
> 写"否定式清单"并没有绕过这条铁律，**它本身就是"对模型说的话"**。

✅ **正解：纯正向音景（不提"语音"二字）**

| 项 | 内容 |
|---|---|
| 常量 | `ONLY_THIS_LINE = " 此段音频里只有这一句对白，其余全是教室的环境底噪与衣料摩擦声。"`（各幕按场景改后半句：act2 为"教室的环境底噪与全息设备低沉的电流嗡鸣"） |

**C. 本机零安装就能做（不碰 GPU ⇒ 跑批期间也安全）**

ffmpeg **已实测**带这些滤镜：`blackdetect` / `freezedetect` / `silencedetect` / `ebur128` / `scdet` / `blend`；`ffprobe` 取规格。

```powershell
# ① 规格 + 音画时长差（同步性），② 黑帧，③ 静帧，④ 静音，⑤ 场景硬切，⑥ 响度

cmd /c "ffmpeg -nostats -v info -i <file> -vf freezedetect=n=-60dB:d=0.5    -an -f null - 2>&1"
cmd /c "ffmpeg -nostats -v info -i <file> -af silencedetect=n=-50dB:d=0.4   -vn -f null - 2>&1"
cmd /c "ffmpeg -nostats -v info -i <file> -vf scdet=threshold=10            -an -f null - 2>&1"
cmd /c "ffmpeg -nostats -v info -i <file> -filter_complex ebur128=peak=true      -f null - 2>&1"
```

### 6.4 ★★ **prompt 禁止写「元信息」**（写进画面描述会被渲染成字幕）

**事故（2026-09-14 镜 91）**：prompt 写了舞台指示
> 「眼神很深、表情看不出情绪，**像在消化一件很难立刻接受的事**」

成片画面底部**真的出现了这行中文字幕**。原因：模型无法表演「像在消化…」这种
**内心状态 / 镜头用意**，它能做的只有"把这句话显示出来"。

**事故二（2026-09-15 镜 5 / 镜 19）—— 比镜 91 更隐蔽**：连**否定式指令**也会被渲染。
- 镜 5 底部字幕「本镜不要生成任何可□旁白」← 来自 `NO_SPEECH` 常量（当时是「本镜不要生成任何…」）
  <br>⚠️ `□` 处**逐字读不准**（两个脚本分别记成「可语午白」「可口旁白」）⇒ 印证 §4.5 E：判"多了字"可以，判"多了什么字"要靠 OCR
- 镜 19 底部字幕「全镜高适」← 疑似同类幻觉（同样存在逐字不确定性）

⇒ 根因统一为：**prompt 里出现"对模型说的话"**（本镜 / 不要生成 / 只允许 / 若画面…），
H3 分不清"指令"与"台词"，一律当词句输出。
📌 **对策**：`NO_SPEECH` 已改成正向音景（见 §4.4）；全片 prompt 用脚本扫一遍（见下）。

| 写法 | 判定 |
|---|:--:|
| ✅ 摄影机拍得到的：动作、表情、景别、光线、环境、人数、衣着 | 安全 |
| ❌ **比喻式内心状态**：像在…／仿佛…／像是…／显得… | **会被画成字幕** |
| ❌ **镜头用意**：暗示…／表达…／说明…／观众要读到…／这是情绪高点 | **会被画成字幕** |
| ❌ **镜头编号指代**：本镜／该镜／这一镜 —— ⚠️ **`NO_SPEECH` 里的「本镜不要生成…」也曾被豁免，2026-09-15 实锤它照样被渲染成字幕 ⇒ 豁免取消，改正向音景（§4.4）** | **会被画成字幕** |

**修法**：改写成可见的物理表现。
```
✗ 像在消化一件很难立刻接受的事
✓ 面无表情地沉默了几秒，喉结动了一下
```

**自查命令**（改完任何 prompt 后跑）：
```powershell

                                         #    ⚠️ 有噪声：R6 的「（后期）」会被 strip_late_audio() 剔除（误报）；
                                         #      R3 误伤词内"不可"（如「几乎不可察」）⇒ 命中需逐条人工核实
py -3.10 OUTPUT/_verify_prompt_clean.py  # ② ★ **闸门**：只校验**拼接后的真 prompt**（含 + CONST 展开），

**⑧ ★★★ 2026-09-16 重大根因：`strip_late_audio()` 吃掉 `\n`，禁令与台词被压成一行**

> **这条推翻了 ① 里「R3 是充分条件」的结论——R3 本身没错，但它被提交环节静默破坏了。**

**现象**：8 个泄漏镜套完 R1–R4 配方、`--verify` 8/8 通过后**重跑，字幕依旧**
（镜 14 逐帧对比：新旧两版同一位置同一文本 `硬硬找补` / `我上次竞选科技之星`，8/8 帧仍在）。

**根因**：`strip_late_audio()` 旧实现是

```python
for sent in _re.split(r"(?<=[；。])|\n", text):   # ← \n 被当作分隔符
    if LATE_MARK in sent: continue
    out.append(sent)
return "".join(out).strip()                        # ← 无条件 join，\n 就此丢失
```

切句时 `\n` 当分隔符、join 时**不还原** ⇒ 多行 prompt 被**压成一整行**。
后果：`Audio:` 前缀所在句含 `（后期）` 被整句剔除，**禁令句与台词句失去段落隔离**，
H3 把整串当同一条指令，禁令对台词失去约束。

**证据链（可复现）**：

```powershell

py -3.10 OUTPUT/_peek_queue.py          # 看 ComfyUI 队列里 node 138 的实际文本
```

坏版本（重跑前，全部挤成一行）：

```
…slow dolly in）。★ 全画面不得出现任何可读的文字、字幕或符号。男生嘴硬地说：我上次竞选科技之星，就输在少说了两句。
```

修复后（3 行清晰分离）：

```
行1: CUT 1: 近景半身镜头。…镜头缓慢向前缓推（slow dolly in）。
行2: ★ 全画面不得出现任何可读的文字、字幕或符号。
行3: 男生嘴硬地说：我上次竞选科技之星，就输在少说了两句。

**修法**：改为**按行处理、保留换行**（6 个 act 脚本 `strip_late_audio()` 已同步）：

```python
lines = []
for line in text.split("\n"):
    kept = [s for s in _re.split(r"(?<=[；。])", line) if LATE_MARK not in s]
    lines.append("".join(kept))
return "\n".join(lines).strip()
```

全片回归（`_regress_strip.py`）：**126 镜文案逐字一致**，证明只恢复结构、不改内容。

#### 6.10.15 ★★ **参考图被静默丢弃：闸门只看 `ref1` 的盲区（镜 4 实测）**

> **一句话**：`ref1`（角色）和 `ref2`（场景）是**两个独立图位**；
> 任何「有没有参考图」的判断**必须两个一起看** —— 只看 `ref1` 会让**纯场景镜**退回无参考的 T2V。

**现象（2026-09-19，镜 4 `paper_plane_over_campus`）**

镜 4 是**航拍纸飞机掠过校园**的纯场景镜 —— 没有角色 ⇒ `ref1=None`，

汇总行仍打印 **`T2V（无角色）`**，注入行也打印 `wf=video_minimax_h3_t2v.json`。

**排查（三步定性，别跳步 —— 呼应铁律 D3）**

| 步 | 查什么 | 结论 |
|:-:|---|---|
| 1 | 源码判据 | `build_video_wf()` 里 `if task["ref1"] is not None:` ⇒ **只看 ref1** |
| 2 | 日志为何自相矛盾 | 打印行**独立**写成 `WF_R2V if task["ref1"] is not None else WF_T2V` ⇒ **用 ref1 反推**，与 `kind` 无关 |
| 3 | 到底跑了哪个工作流 | 查 ComfyUI `/history` 的**实际提交图**（唯一权威） |

第 3 步是本节能定性关键 —— **读脚本不如读 ComfyUI 收下的那张图**：

⇒ **参考图其实接上了**，走的是 R2V。**只有日志在说谎。**

> ⚠️ **但这次是运气好** —— 定性的三步里，第 1 步已经确认**代码判据本身是错的**：
> 若换一个 `ref2` 有值、`ref1` 为空的镜，`load_workflow(WF_T2V)` 会真的执行，
> `ref2` 就**真的被丢掉**、且**日志还会说 `kind=R2V`**（因为 `kind` 在 R2V 分支里赋）——

has_any_ref = (task["ref1"] is not None) or (task["ref2"] is not None)
if has_any_ref:
    ...
    fill = ref1_name or ref2_name
    wf[load_nodes[0]]["inputs"]["image"] = ref1_name or fill
    wf[load_nodes[1]]["inputs"]["image"] = ref2_name or fill

print("  注入：wf=%s kind=%s ..." % (WF_R2V if kind == "R2V" else WF_T2V, kind, ...))
print("[镜 %d] ... | %s" % (..., "T2V（无参考图）" if (task["ref1"] is None and task["ref2"] is None)
                                  else "R2V | <Picture 1> = %s" % os.path.basename(task["ref1"] or task["ref2"])))

### 6.9 ★★★ **画面里的招牌 / 校名：怎么写才对（镜 1，四轮实测）**

> **这是 §6.7 的一个特例，但根因不同。** §6.7 是「我们**主动要求** H3 写字，它写错」；
> 本节是「我们只想要个**场景**，却因为一句『校牌清晰可见』把 H3 引上了写字的路」。

**现象与四轮对照**（镜 1 `girl_mother_at_school_gate`，读帧实测）

| 轮次 | prompt 做法 | 校名结果 | 判定 |
|:-:|---|---|:-:|
| 一 | 「校牌清晰可见、完整入画」 | 乱码，且**跑到墙上**新造了一块招牌 | ❌ |
| 二 / 三 | 反向：把墙面写成"白板"、「看不到可辨认的笔画」 | 校名**彻底消失**，只剩抽象红方块；构图退化成**墙面纹理特写** | ❌ **过度防御** |
| 三改 | 「照抄 \<Picture 2\> 里的校名」+ 禁额外文字 | 校名**出现了、位置对、红圆徽对**，但字错：`里江勇舱学校` / `Shanppr Apennial Shoule` | ⚠️ 半对 |
| **四（定版）** | **逐字写出目标字符 + 机位推近 + 逐词给英文** | **`上汇实验学校` / `Shanghai Experimental School` —— 全对** | ✅ **正解** |

**★ 为什么第一轮会失败**：prompt 写了 `校牌清晰可见`，但当时 `ref2` 用的是另一张图，
且**没有锁定"照参考图原样"** ⇒ H3 按「要有一块显眼的招牌」**自己发明了一块**，字才跑到墙上。
**这是"发明文字"的失败，不是"照抄失败"。** 补上「照抄参考图」之后（第三改），字就回到门柱上、位置也对了。

**★ 为什么第三改字还是错：H3 对汉字走「按字形结构相似性合成」**

实测错字与正字的**结构高度同源** ——

| 正字 | 实测错字 | 相似点 |
|---|---|---|
| 上 | 里 | 都是"横 + 竖"骨架 |
| 汇 | 江 | 都是"三点水 + 声旁"左右结构 |
| 实 | 勇 | 上下结构、中部都有"力/冖"感 |
| 验 | 舱 | 都是"舟/马"系偏旁 + 右侧复杂部件 |
| `School` | `Shoule` | 末三字母形状接近 |

⇒ 「照抄」被 H3 理解成**「请在这里画出一些汉字」**，它便从潜空间采样一串**"看起来像校名的字"**，
而不是去**复制那 7 个特定字符**。**与 §6.7 结论一致：H3 走"文本渲染"路径，中文不可靠。**

**★ 正解（两条必须同时用）**

| # | 做法 | 为什么有效 |
|:-:|---|---|
| **①** | **把目标字符序列本身写进 prompt**：`这组字是七个汉字「上汇实验学校」` + `七个汉字就是上、汇、实、验、学、校这七个字`；英文**逐词**写 `「Shanghai」「Experimental」「School」` | 给模型一个**明确的 token 序列**去对齐，不再是"自由合成像字的字" |
| **②** | **把机位推近，让字够大**：`全景镜头` → `中景镜头`，并保留"完整入画门柱" | 0.6MP 输出下，参考图里约 38px 高的字经 R2V 后会糊成一团；**字高不够时 ① 也无从生效** |

> ⚠️ **与铁律 A4「对模型说的话不能进 prompt」的边界**：写明字符锚点是**画面用途**
> （"这里应该有这几个字"），不是"对模型说的话"。为免被当台词念，本条要求：
> **字符锚点放在 `Audio:` 段之前**，且**不带"读作 / 念作 / 配音"等字样**，
> `Audio:` 段只保留真正的台词（本镜由 `ONLY_THIS_LINE` 收口）。实测 ASR 未把校名当台词念出。

**★ 两条禁令**

- ⛔ **不要发明参考图里没有的文字**：横幅 / 标语 / 广告 / 第二块招牌 / 水印角标一律禁止。
- ⛔ **不要为了躲一个"并不存在的抄不动问题"而把参考图里的实体信息删掉**。
  第二/三轮「把墙写成白板」就是这种**过度防御**，结果展示镜的核心功能丢失。
  用户原话：「参考图中已经有『上汇实验学校』字样了，保持即可，不要搞成白板，对 AI 这么不自信吗？」

> 📌 **推广**：全片凡是画面里**天然有文字**的地方（校名 / 门牌 / 报纸 / 标语 / 广告），
> 一律按本节处理。需要**参考图里没有**的真实文字时走**后期烧字**（§6.7 / `_burn_cards.py`）。
> 📌 **本节曾有一条错误结论**（「明示正确校名让它照写 → ❌ 无效」），
> 于 2026-09-19 被第四轮实测**推翻**（见上表第四行），已从正文删除；
> 完整证伪过程与实测数据见 `OUTPUT/_readme_history.md`。
