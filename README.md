### 4.2 看图与验收（★ 2026-09-13 更新：主模型已能直接看图）

**① 主模型（我）现在可以直接读图**（此前不支持，用户已更换底座模型）。但有一条硬限制：

> ⚠️ **每条会话的图片投递额度有限**：实测同一会话读到第 **~7 张**之后，**后续图片会被静默丢弃**
> （连 **6.8 KB** 的小图也丢，工具只回 "media omitted: invalid or exceeds size limit"；**新开会话即恢复**）。
>
> **省额度三招**：
> · **只读最关键的那几张**，读完立刻下结论，不要重复读同一张；
> · 大图先用 `OUTPUT/_view.py` 生成 **≤1024 px JPEG 预览**（超大图会被 read 工具直接拒收）；
> · **把多张拼成一张 montage / 对照图再读** —— 一张图承载 N 条信息，是最省的用法。

**② 本地视觉模型 `qwen3.5:latest`**（兜底 / 可脚本化批量核查）：

| 项 | 值 |
